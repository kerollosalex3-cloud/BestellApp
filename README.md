# BestellApp — BurgerHouse

A responsive food ordering page built with plain HTML, CSS and JavaScript from the supplied Figma design.

## Run

Open `index.html` in a browser. No installation, packages or build command are needed. Images and fonts are included locally.

## Features

- Burger, pizza and salad menu with the original design images.
- Basket with quantities, removal, delivery fee and total.
- Saved basket after a page reload.
- Order confirmation and an empty basket after checkout.
- Mobile layout, bottom navigation and basket overlay.
- Keyboard controls and accessible button labels.

This is a student demonstration. Checkout does not send a real order, process a payment or contact a delivery service. The imprint explains this; real restaurant operator details were not supplied.

## Files

- `index.html` — page content.
- `style.css` — desktop and responsive styles.
- `script.js` — basket, navigation and dialogs.
- `assets/` — local images, fonts and font licenses.
- `DESIGN.md` — saved measurements, design decisions and verification.
