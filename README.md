# BestellApp

A food ordering website built with HTML, CSS and JavaScript, based on the supplied Figma design.

## Run the project

Open `index.html` in your browser. No installation or build command is needed.

## Files

- `index.html`: page structure.
- `style.css`: page styles.
- `script.js`: page interactions.
- `assets/images/`: design images and icons.
